🚀 AI Content Reviver

An AI-powered content enhancement application that transforms raw text into engaging, platform-specific social media posts. The application leverages the **Groq Llama 3.3-70B Versatile** language model to rewrite content, generate compelling hooks, suggest relevant hashtags, improve readability, and adapt writing style based on the selected platform, tone, and length. Built using **Python**, **Streamlit**, and the **Groq API**, it provides creators and professionals with a fast and efficient way to produce high-quality social media content.

✨ Features
 🔹 Rewrite raw content into engaging, platform-specific posts using AI.

🔹 Generate content tailored for:
  * LinkedIn
  * Instagram
  * Twitter (X)
    
🔹 Choose from multiple writing tones:
  * Professional
  * Casual
  * Motivational
  * Friendly
  * Humorous
  * Persuasive

🔹 Adjust post length:
  * Short
  * Medium
  * Long

🔹 Smart emoji controls:
  * Add relevant emojis
  * Generate emoji-free content

🔹 AI-generated attention-grabbing hooks to improve engagement.

🔹 Automatically suggests relevant hashtags based on the generated content.

🔹 Provides content improvement suggestions to enhance readability, clarity, and audience impact.

🔹 Generates polished, platform-optimized content using the **Groq Llama 3.3-70B Versatile** language model.

🔹 Simple, responsive, and user-friendly interface built with Streamlit.

🔹 Secure API key management using environment variables.
